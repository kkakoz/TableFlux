## ADDED Requirements

### Requirement: 数据结果区工具栏控件尺寸变体

在保持全局紧凑型视觉密度的前提下，**数据结果区**（单表与 SQL 结果网格上方或紧邻的工具栏）中的**分页、刷新**等高频操作控件 SHALL 允许使用**较大尺寸变体**，其高度与可点击区域 SHALL 大于默认紧凑小按钮规范中定义的基础值；该变体 SHALL 通过集中样式（CSS 变量或共享类名）定义，避免在结果区随意使用互斥的魔法数。

#### Scenario: 变体与全局规范并存

- **WHEN** 贡献者查看「前端紧凑 UI」规则与数据结果区工具栏实现
- **THEN** 二者明确说明结果区分页/刷新使用「较大变体」，且其他区域默认按钮仍遵循紧凑小尺寸规范

#### Scenario: 结果区控件仍满足可访问最小点击区域

- **WHEN** 用户使用数据结果区分页或刷新控件
- **THEN** 控件点击区域不低于项目为桌面端记录的最小可点击区域要求
